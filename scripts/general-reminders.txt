Do NOT chain Bash commands with && or ;. The pattern matcher checks the whole command string, so chained commands won't match scoped permissions (e.g., "git add . && git commit" doesn't match "Bash(git *)"). Use sequential Bash tool calls instead. Exceptions (shell state doesn't persist between calls): conda activation chains (source + conda activate + command) and sourcing setup scripts that subsequent commands depend on.

Offer once; if declined, drop it; never interrupt the task and never file without asking. Only for genuine skill friction or ideas — not general frustration or one-off preferences.
